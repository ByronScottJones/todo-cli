Commands

Help is available with -h, -H, --help, --HELP or -?.

Command-line commands
Command Description
todo add item <subject> Add an item. Options: --list <name>, --star, --due-date <yyyy-MM-dd|MM-dd>.
todo add list <name> Add a list.
todo list List items. Options: -a/--all, --no-status.
todo complete <id> Mark an item as completed.
todo remove Remove items.
todo tui Open the terminal UI.

-o Json switches the command-line commands to JSON output. The first use opens a browser window to sign in to your Microsoft account.

Terminal UI

Run todo tui, or just todo in an interactive terminal. The screen has a title bar, a menu bar, a context line (list, counts, search, and how many items are scrolled out of view), the item list, a status line and a key bar. It adapts to the terminal size and shows a warning below 60 columns by 12 rows.

If input or output is redirected, todo tui exits with code 2, and bare todo prints help instead.

Keys

Every action works from the keyboard. Custom commands use Alt plus a letter, with a Ctrl alternative that is shown instead when Alt cannot be confirmed. Both always work.

Terminal UI key bindings
Key Action
Alt+N / Ctrl+N New item
Alt+M / Ctrl+E, Enter Modify the selected item
Space, Alt+C / Ctrl+T Complete or reopen
Alt+I / Ctrl+P Mark or unmark important
Delete, Alt+R / Ctrl+R Remove, after confirmation
Alt+L / Ctrl+L Choose the list shown
?, Alt+S / Ctrl+F Search by subject
Alt+A / Ctrl+A Show or hide completed items
Ctrl+C Copy the selected subject (the selection in text fields)
F1 Help
F3, Alt+X Exit; F3 closes an open dialog instead
F5 Reload from Microsoft To Do
F7 / F8, PgUp / PgDn Page up or down
F10 Menu bar; Alt+T, Alt+F, Alt+E, Alt+V, Alt+H open menus
Tab / Shift+Tab Move between controls
Esc Cancel a dialog or close a menu; it never exits the program

Ctrl+Q is not used because terminals reserve it for flow control. In a dialog, Enter activates OK and Esc activates Cancel.

Item form

  • Subject is required.
  • Due date is optional: yyyy-MM-dd or MM-dd (current year). Blank means none; clearing it on an existing item removes the due date.
  • Important is a checkbox.
  • List is chosen when adding. Items cannot be moved between lists.

OK stays disabled and an inline message beginning with ! is shown until the form is valid.

Alt and Option keys on macOS

Many macOS terminals capture the Option key instead of sending it as Alt. At startup the UI checks whether Alt can be relied on: for Terminal.app it reads the useOptionAsMetaKey setting of the default profile, and other macOS terminals count as unconfirmed. When Alt is unconfirmed the key bar and menus show the Ctrl alternatives.

To use Alt, enable Use Option as Meta key in your terminal profile, or set Tui:AltKeys to on.

Configuration

The optional appsettings.json next to the executable has a Tui section. Environment variables prefixed TODO_, with __ as the separator, override it, for example TODO_Tui__AltKeys=on. 

{
  "Tui": {
    "AltKeys": "auto",
    "Palette": {
      "Background": "Black",
      "Foreground": "White",
      "Accent": "Blue",
      "AccentText": "White",
      "Selection": "White",
      "SelectionText": "Black",
      "Warning": "Yellow",
      "Error": "BrightRed",
      "Muted": "DarkGray"
    }
  }
}
  • AltKeys: auto, on or off.
  • Palette: terminal color names or hex values. An unrecognized color is replaced by its default and the status line says so.
  • Color is never the only signal: completed items use ☑, important ones ★, overdue ones !, and errors begin with !.
  • NO_COLOR (any non-empty value) selects a monochrome display.
  • Without a UTF-8 locale the UI uses ASCII symbols.

Exit status

Exit codes
Code Meaning
0 Success
1 The command or the UI failed
2 todo tui started without an interactive terminal
